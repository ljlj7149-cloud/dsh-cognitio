## 这是什么

cognitio（认知·张力网络）是一个 **DeepSeek Harness 插件**，把"AI 的记忆与自律"从凭自觉变成机制：

- **记忆**是分层的（事实/规矩/模式/案例/命题），改过的内容永远能查旧版（版本链）
- **提醒**是机械触发的（每回合/动作前/出错/回合末自动检索），不依赖模型记住你定的规矩
- **进化**是纠错驱动的（出错 → 自动归档 → 每日提炼 → 你批准 → 成为新规矩）
- **你永远是仲裁者**：一切自动产物只进草稿，批准才转正（审批面板可见可一键批）

一句话：**它是"会自我进化的规矩与记忆系统"，不是一个聊天机器人。**

## 怎么用（安装与配置）

### 安装

```sh
# 方式 A：从 GitHub 直接安装（推荐，生态惯例）
dsh plugin --profile web add github:ljlj7149-cloud/dsh-cognitio

# 方式 B：npm 包（发布后）
dsh plugin --profile web add dsh-cognitio-core

# 方式 C：本地目录（自托管/开发）
dsh plugin --profile web add file:/path/to/dsh-cognitio
```

安装后 **重启 DSH**（插件清单在启动时装载一次）。重启后：设置 →「cognitio 系统」。

### 配置（可选）

| 环境变量 | 作用 | 默认 |
|---|---|---|
| `MEMORY_DIR` | 记忆数据目录 | `~/.dsh/cognitio` |
| `VAULT_DIR` | 文献库目录 | `~/.dsh/cognitio/vault` |
| `VAULT_INDEX_DB` | 文献索引文件 | `<vault>/vault-index.sqlite` |

首次启动自动初始化数据目录；不配置也能用（默认路径）。

### 三分钟体验

1. 装好并重启后，打开 设置 →「cognitio 系统」
2. 「记忆库」页：看到分层记忆 + 状态（已生效/待审批）+ 筛选胶囊（全部/事实/规矩/模式/案例/命题）
3. 「规则」页：生效中的规矩（50 条+）与待你批的规矩分区显示；点条目展开定义/触发词/失效条件
4. 在任意会话重复说一句话——哨兵按需注入相关规矩（人工验证触发链路）

## 设置页 / cognitio 系统

DSH 设置 →「cognitio 系统」：

- **记忆库**：全量记忆 + 类型筛选 + 前缀搜索 + 行内展开详情 + 待审批条目就地批准/毙掉
- **命题与范畴**：我们总结的"毛病类型"看板（案例计数/状态/成熟度），供你仲裁重点
- **规则**：🔵 生效中的规矩 / 🟡 待你批的规矩（分组），反例覆盖标记（✓/⚠）
- **待裁决**：等待你拍板的决策队列（选项下拉 → 按所选方案执行）
- **审计流**：谁在何时对哪条记忆做了什么（人话翻译：写入/批准/毙掉/补记）；近 7 天疑似未走审批即转正的可疑项，可补记

## 架构

```
哲学内核：张力网络（命题可推翻 + 反例 + 外部锚点）· 纠错驱动进化 · 用户仲裁
┌─────────────────────────────────────────────┐
│ ⑦ 治理层   审批面板 + 决策队列 + 审计链（你仲裁）│
│ ⑥ 知识层   文献井（只读 FTS）+ 强制查库义务     │
│ ⑤ 观测层   注入审计 + 六维指标 + 死规矩/推翻候选 │
│ ④ 沉淀层   出错归档 / 回合归档 / 每日维护       │
│ ③ 触发层   哨兵：回合/动作/出错/回合末 四面注入  │
│ ② 检索层   FTS5 + 触发词双向 + 证据加权 + 衰减   │
│ ① 数据层   SQLite：版本链/关系表/效力成绩单     │
└─────────────────────────────────────────────┘
        ↕ 事件钩子（pre-step/turn-stopping/error/pre-execute）
        ↕ 宿主：DeepSeek Harness（bundle 插件形态，plugin_check 体检通过）
```

## 数据与隐私

**本仓库不含任何记忆数据。** 你的记忆、项目内容与凭据永远留在你的机器：

- 数据目录（`~/.dsh/cognitio` 或 `MEMORY_DIR`）不在仓库内
- npm 包 `files` 白名单只含机制代码
- `scripts/pre-commit-guard.sh` 在提交时拦截数据/凭据/临时产物
- 记忆写入经 no-secrets 扫描（检测器自身豁免逻辑见脚本注释）

## FAQ

**Q：装了会改变我的 AI 行为吗？**
A：只增不减——多一套"该守规矩时的提醒"；所有提醒内容来自你自己的记忆库，可随时在设置页查看/删除。

**Q：和普通记忆插件（如 dsh-memoir）区别？**
A：它们多是"会话归纳→存文件"；cognitio 是完整闭环：触发-沉淀-治理-审计-进化，且所有自动产物必须你批准，并有六维自监控。

**Q：换模型/换预设会失效吗？**
A：不会。提醒是机械注入（不依赖模型自觉），挂在宿主总装层（与预设解耦）——这是本项目核心设计目标之一。

**Q：能贡献吗？**
A：欢迎 PR/Issue（机制增强、测试、文档）。注意别提交含个人记忆数据的 dump。
